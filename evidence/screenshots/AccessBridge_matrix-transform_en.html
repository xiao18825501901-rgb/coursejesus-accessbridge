Matrix transforms

Scale, rotate, and translate an object in a fixed order

The offline file contains only the exported lesson, answers, and feedback. It does not provide offline AI.

Text-equivalent source

This example uses homogeneous column vectors p=(x,y,1)^T. We choose scale S, then rotation R, then translation T, so p'=T R S p. This is an explicit example order, not a universal default. Affine translation uses homogeneous coordinates.

Start from coordinates

Represent the point (1,0) as the homogeneous column vector (1,0,1)^T. This lets a 3x3 affine matrix express translation as well as scale and rotation.

Apply one matrix at a time

For this lesson only, apply S then R then T, giving p'=T R S p. The rightmost matrix acts first on a column vector; there is no universal default order.

Compare the result

Scale (1,0) by 2 to (2,0), rotate 90 degrees counterclockwise to (0,2), then add (1,1) to get (1,3). Reversing the operations gives (-2,4). Results can differ, though some special transformations commute.

Short practice

1. After scaling (1,0) by 2 and rotating 90 degrees counterclockwise, what point do you have before translation?

✓ (0,2)

○ (1,3)

○ (2,0)

Scaling gives (2,0); a 90-degree counterclockwise rotation maps it to (0,2).

2. After translating (0,2) by (1,1), what is the final point?

✓ (1,3)

○ (0,3)

○ (2,1)

Adding (1,1) to (0,2) gives (1,3). The composition is p'=T R S p for this explicit order.

3. What is the reversed-order control result for translation, then rotation, then scaling?

✓ (-2,4)

○ (1,3)

○ (-4,2)

Translation gives (2,1), rotation gives (-1,2), and scaling gives (-2,4). This differs from the forward result (1,3); some special transforms can still commute.
