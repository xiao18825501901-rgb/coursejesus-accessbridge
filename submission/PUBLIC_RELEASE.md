The public judging experience runs the API-independent AccessBridge surface from
the same competition source tree. It needs no course account or private data.
The complete guest shell and FastAPI isolation boundary are verified locally.
The owner representative course, live image/video flow, production RAG/Agent
E2E, and public full-stack API remain separate unverified boundaries.

CourseJesus-authored source is publicly viewable with rights retained and an
evaluation permission for judges. It is not presented as OSI open source.
Third-party components retain their existing licenses.
